## Headings become sections

Use `##` for section headings. Body text is set in a narrow column so lines stay
comfortable to read.

> **Key point.** A blockquote renders as a tinted callout box.

## Code

```yaml
steps:
  - id: decide
    on_low_confidence: human_review
```

Inline `code`, [links](https://themeli.me) and lists all pick up the site's
colours.
